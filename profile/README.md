# 🐵 Threepwood Py Labs

### Focused, open-source Windows desktop tools — built with Python & PySide6

Practical apps for **media, downloads, files, and developer workflows**.
Every app release ships a portable **`.zip`** and a single-file **`.exe`**, with SHA-256 checksums and build-provenance attestation.

## ✨ What ties it together

- **Windows-first** PySide6 desktop apps with a consistent look and behavior.
- **Quality bar in CI** — linted, strictly type-checked, and tested with coverage gates.
- **Reproducible releases** — single-file `.exe` + portable `.zip` + `SHA256SUMS.txt` + signed build attestation.
- **Shared foundation** — common runtime in `threep-commons`, scaffolded from one Copier template.
