# Threepwood Py Labs

Threepwood Py Labs is a collection of focused Windows desktop tools, shared
Python runtime libraries, and workspace automation built around practical
PySide applications.

## Applications

- [arr-helper-ui](https://github.com/threepwood-py-labs/arr-helper-ui) - Sonarr helper and media quality checker.
- [prowlarr-ui](https://github.com/threepwood-py-labs/prowlarr-ui) - Prowlarr search client with Everything duplicate checks.
- [qbiremo-enhanced](https://github.com/threepwood-py-labs/qbiremo-enhanced) - advanced qBittorrent desktop client.
- [video-duperz](https://github.com/threepwood-py-labs/video-duperz) - perceptual duplicate video finder.
- [many-panelz-explorer](https://github.com/threepwood-py-labs/many-panelz-explorer) - multi-panel Windows file explorer.
- [git-statuz](https://github.com/threepwood-py-labs/git-statuz) - Git repository status and history viewer.
- [mp3gain-gui-py](https://github.com/threepwood-py-labs/mp3gain-gui-py) - PySide port of MP3Gain workflows.
- [pdf-search-downloader-ui](https://github.com/threepwood-py-labs/pdf-search-downloader-ui) - desktop PDF search and download helper.
- [web-pagez-to-pdf](https://github.com/threepwood-py-labs/web-pagez-to-pdf) - Windows-focused page capture utility.
- [backlogooze](https://github.com/threepwood-py-labs/backlogooze) - backlog and workspace planning assistant.

## Shared Building Blocks

- [threep-commons](https://github.com/threepwood-py-labs/threep-commons) - shared runtime and utility package.
- [_py_template](https://github.com/threepwood-py-labs/_py_template) - Copier template for consistent Python app repositories.
- [_py_workspace](https://github.com/threepwood-py-labs/_py_workspace) - workspace automation, specifications, and materialization scripts.
